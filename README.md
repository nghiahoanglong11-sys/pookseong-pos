# PookSeong POS

A clean React + Vite starter for the PookSeong POS system.

## Features included
- POS product grid and cart
- Inventory table with low-stock warnings
- Customers overview
- Settings page
- Customer portal section
- localStorage persistence using Zustand

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
This scaffold is designed to be the baseline for a production POS system. It is intentionally modular so features can be expanded safely without dumping everything into a single HTML file.
